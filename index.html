How To Run The Application

Installation & Execution Guide

Follow these 3 simple steps to download and launch the Smart Study System desktop application on Windows, macOS, or Linux.

1

Verify or Install Java

This is a native Core Java application and requires Java Runtime Environment (JRE) or Java Development Kit (JDK) version 8 or higher installed on your computer.

java -version
2

Download the Application JAR

Click the download button to save SmartStudySystem.jar directly to your computer.

Download SmartStudySystem.jar
3

Launch the Desktop Application

On Windows or macOS, you can simply double-click SmartStudySystem.jar to launch. Alternatively, open your command prompt/terminal in the downloaded folder and run:

java -jar SmartStudySystem.jar
